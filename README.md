# Kalam Dawat Puja

A single-page interactive tribute to Shri Chitragupt Maharaj Ji, made for Kalam Dawat Puja (Kartik Shukla Dwitiya, Vikram Samvat 2083).

Created by Prakhyat Nandan Srivastava.

## What is in it

- Five scenes: the threshold, the scribe, the writing desk, the offering of study, and a colophon.
- A pen that writes श्री चित्रगुप्ताय नमः and सीता राम on a manuscript, line by line, timed to the music's beat.
- Puja mode: the writing desk goes full screen and the pen keeps writing, for keeping the laptop open beside the books during the puja. Press Esc to leave.
- A notebook where you can type your own line and watch the pen write it.

## Running it

Open `index.html` in a browser. No build step and no server are needed. The fonts load from Google Fonts, so the handwriting looks right only with an internet connection.

## Files

- `index.html`: the whole page (markup, styles, script).
- `assets/`: images in WebP and the background track, `morning-at-the-ghat.mp3`.
